# 혹시요 테스트 가이드

혹시요는 일러스트레이터가 받은 수정 피드백을 분석해 **바로 작업할 항목, 확인이 필요한 항목, 의뢰인에게 물어볼 질문**으로 정리해 주는 에이전트입니다.

피드백을 어떻게 해석해야 할지 고민되는 순간, 혹시요를 사용해 보세요!

## 1. 접속하기

[혹시요 바로가기](https://hoksiyo-frontend.jiyoungbkim.workers.dev/)

- **접속 코드:** 398d00c184a9

> 무료 사용량 한도 안에서 운영하고 있어 하루에 분석할 수 있는 횟수가 제한됩니다. 입력 내용에 따라 분석 가능 횟수는 달라질 수 있습니다. 한도 초과 안내가 나오면 다음 날 다시 이용해 주세요.

## 2. 입력 방법

화면에 표시된 입력 항목을 작성해 주세요.

| 입력 항목 | 필수 여부 | 작성 내용 |
|---|---|---|
| 프로젝트명 | 필수 | 작업 중인 프로젝트나 작품 이름 |
| 피드백 원문 | 필수 | 의뢰인에게 받은 수정 피드백 전체 |
| 전달자 | 선택 | 피드백을 전달한 사람 (예: 출판사 편집자) |
| 전달 경로 | 선택 | 이메일, 메신저 등 피드백을 받은 경로 |
| 이전 피드백 | 선택 | 현재 피드백과 비교할 이전 수정 요청 |

**테스트할 때 참고해 주세요.**

- 실제 업무에서 받은 피드백뿐 아니라 직접 만들어 본 가상의 피드백도 괜찮습니다.
- 실제 피드백을 사용할 때는 이름, 연락처 등 개인정보를 반드시 삭제해 주세요.
- 텍스트를 기준으로 분석하며, 이미지나 시안 자체는 분석하지 않습니다.
- 피드백이 너무 길면 안내에 따라 여러 번 나누어 입력해 주세요.

## 3. 바로 써 볼 수 있는 예시

각 예시의 프로젝트명과 피드백 원문을 해당 입력란에 복사해 넣으면 됩니다. 전달자와 전달 경로는 필요에 따라 입력해 주세요.

### 예시 A. 한 문장에 여러 수정 요청이 있는 경우

`기본 기능 테스트`

**테스트 목적:** 여러 요청을 빠짐없이 분리하고, 그대로 유지해야 할 사항도 놓치지 않는지 확인합니다.

**프로젝트명**
```text
《바다로 간 고양이》 그림책 삽화
```

**전달자:** 그림책 작가

**전달 경로:** 메신저

**피드백 원문**
```text
고양이 꼬리를 조금 더 길게 그려주시고, 4장 파도는 더 크게 해주세요. 아이들이 보기엔 지금 파도가 너무 잔잔해 보여요. 고양이 눈 색은 지금 초록색 그대로 두세요.
```

### 예시 B. 여러 방향으로 해석할 수 있는 경우

`모호성 판단 테스트`

**테스트 목적:** 추상적이거나 감각적인 표현을 임의로 해석하지 않고, 가능한 해석과 확인 질문을 제시하는지 확인합니다.

**프로젝트명**
```text
《겨울 도서관》 삽화
```

**전달자:** 출판사 편집자

**전달 경로:** 이메일

**피드백 원문**
```text
전체적으로 좀 더 따뜻한 느낌이면 좋겠어요. 소녀 표정이 살짝 어색한 것 같고요. 여기 책장 쪽은 뭔가 허전해 보여요.
```

### 예시 C. 구체적인 맥락이 없는 경우

`예외 처리 테스트`

**테스트 목적:** 수정 대상이나 방향을 알 수 없을 때 억지로 작업 내용을 만들어 내지 않고, 필요한 정보를 되묻는지 확인합니다.

**프로젝트명**
```text
《겨울 도서관》 삽화
```

**피드백 원문**
```text
음, 이건 좀 아닌 것 같아요. 처음부터 다시 생각해 주실 수 있을까요?
```

### 예시 D. 이전 피드백을 참고해야 하는 경우

`이전 맥락 대조 테스트`

**테스트 목적:** 이전에 전달된 수정 요청과 현재 피드백을 비교하고, 관련 내용을 찾거나 충돌 여부를 확인하는지 살펴봅니다.

**프로젝트명**
```text
《작은 정원사》 2장 삽화
```

**전달자:** 그림책 작가

**전달 경로:** 메신저

**이전 피드백**
```text
소년이 들고 있는 물뿌리개를 좀 더 크게 그려주세요. 정원 꽃은 지금처럼 노란색 위주로 유지해 주세요.
```

**피드백 원문**
```text
저번에 말씀드린 물뿌리개는 조금 더 키워주세요. 그리고 꽃은 분홍색이 더 많았으면 좋겠어요.
```

## 4. 분석 결과 확인하기

분석이 완료되면 아래 세 가지를 봐 주세요.

- **분류:** '바로 작업할 항목'과 '확인이 필요한 항목'이 납득되게 나뉘었나요?
- **정확성:** 원문의 요청이 빠지거나, 원문에 없는 내용이 추가되지는 않았나요?
- **질문:** 의뢰인에게 그대로 보내거나 조금만 다듬어 쓸 수 있나요?
